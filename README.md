# Portal de Eventos & Comércio do Bairro

Projeto autoral de front-end: uma página para divulgar eventos e comércios locais do bairro, permitindo cadastro de eventos e de estabelecimentos comerciais.

##  Tecnologias

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (em desenvolvimento)

##  Responsividade

O layout se adapta a diferentes tamanhos de tela (mobile, tablet e desktop):
- Grid responsivo com `minmax()` para evitar overflow horizontal
- Tipografia fluida com `clamp()`
- Breakpoints para reorganizar o layout em telas menores

##  Páginas

- `index.html` — página inicial, com acesso ao cadastro de eventos e de comércios
- `cadastro-eventos.html` — formulário de cadastro de evento
- `cadastro-novo-tipo-de-evento.html` — formulário para sugerir um novo tipo de evento
- `cadastrar-comercio.html` — formulário de cadastro de comércio
- `lista-de-eventos.html` — lista de eventos cadastrados
- `lista-de-comercios.html` — lista de comércios cadastrados

##  Como rodar

1. Clone o repositório
2. Abra o `index.html` no navegador (ou use uma extensão como Live Server)
